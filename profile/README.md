# Hubisum

*Ubi sum?* is Latin for "where am I?". Hubisum answers that question for local businesses.

It keeps one record per business: name, address, phone, opening hours, menu or services, prices and how to book. That record feeds the places where people and AI assistants look: Google and Apple Maps, OpenStreetMap, the business's own website and booking page. Later it will also feed an API and an MCP server that agents can call directly.

The first town is Sesimbra, Portugal, starting October 2026.

## Status

Early. The code stays private while we test the service with the first businesses. Public repositories will be listed here once there is something you can use.

## How we work

- We publish only facts the owner has confirmed, from accounts the owner controls.
- Our OpenStreetMap edits follow the Organised Editing Guidelines and are disclosed as paid editing.
- We improve the facts AI assistants read. We don't promise rankings or mentions.
